# Psc-sonia

Landing page de la Psicóloga Sonia Katherine Martínez — terapia online en español.

Sitio estático (HTML, CSS y JavaScript vanilla, sin frameworks ni build step), pensado para desplegarse directamente en GitHub Pages.

## Estructura

```
index.html      Marcado de toda la landing
style.css       Estilos (tokens de color, tipografía, layout, responsive)
script.js       FAQ acordeón, selector de zona horaria, botón flotante de WhatsApp
assets/         Ilustraciones de las "criaturas emocionales" (Chispa, Sereno, Dulce, Brillo, Curioso, Todos juntos)
```

## Desarrollo local

No requiere instalación ni build. Basta con abrir `index.html` en el navegador, o servirlo con cualquier servidor estático, por ejemplo:

```bash
npx serve .
```

## Despliegue

Publicado con GitHub Pages desde la rama `main` (carpeta raíz).
